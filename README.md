High-converting, Dark Neo-Agency React website for **Outprix Digital**, founded by **Bajrang Choudhary** in Jaipur, India.

## 🚀 Instant Quick Start (Zero Dependencies Required)

The project is pre-configured with a zero-dependency standalone build in `index.html`:

1. Simply double-click `index.html` in your file explorer, or right-click and choose **Open with > Chrome / Edge / Brave**.
2. The entire multi-page React application will load and run instantly with full interactivity, client-side routing, the ROI calculator, and strategy call booking flow!

## 🌐 Deploying to Production

You can deploy this site in less than 2 minutes:

### Option A: Vercel / Netlify / GitHub Pages (Static Hosting)
1. Upload this folder (`outprix-digital`) to a GitHub repository.
2. Link the repository to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
3. If deploying statically, the root directory with `index.html` and `assets/outprix-logo.jpg` deploys with 0 build steps.

### Option B: Traditional cPanel / Hostinger
Upload `index.html` and the `assets/` folder directly to your `public_html` directory.
